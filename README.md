# PitTrack
A lightweight equipment inventory and maintenance tracker for robotics teams, school clubs, and makerspaces.

Problem
Teams need a simple way to track equipment, checkouts, returns, and maintenance issues.

Planned Features
- Add and view equipment
- Update equipment details
- Track checkouts and returns
- Record maintenance issues
- Search and filter equipment

Technology Stack
- Java
- Spring Boot
- PostgreSQL
- Thymeleaf
- JUnit

Project Status
Currently in development.

Learning Goals
Practice backend development, database design, testing, version control, and deployment.
